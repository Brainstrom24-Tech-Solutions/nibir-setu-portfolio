# Nibir Setu — Premium Digital Marketer Portfolio

Next.js + Tailwind CSS + GSAP portfolio focused on Nibir Setu's positioning as a **Digital Marketer / Meta & Google Ads Expert**.

## Stack
- Next.js 14 (Pages Router)
- Tailwind CSS 3
- GSAP + ScrollTrigger
- React Icons

## Positioning
The visual hierarchy follows the supplied portfolio deck:
- HI THERE!
- I'M NIBIR
- DIGITAL MARKETER
- META & GOOGLE ADS EXPERT

## Run
```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.
